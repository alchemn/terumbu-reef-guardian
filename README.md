Terumbu — Reef Guardian is a vibrant 2D canvas game: you are a sea turtle guardian of a coral reef, gathering glowing pearls and plankton to restore the reef to 100% while dodging lionfish, jellyfish, sharks and drifting plastic trash across 5 rising waves. Chain pickups for a combo multiplier, grab bubble shields, magnets and starfish, and watch the grey reef bloom back to colour as you restore it. All art is drawn procedurally on canvas and all sound is synthesised with WebAudio — no external assets, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.

## Controls

- **WASD / arrow keys** or **mouse** — steer the turtle
- **Space / Enter / click** — start, restart
- **P / Esc** — pause
- **M** — mute
- **R** — restart after game over or victory

## Rules

- Collect pearls (+3% reef) and plankton (+1% reef) to restore the reef.
- Reach **100% reef to win**. Lose all **3 hearts** and the reef fades.
- 5 waves, each faster and busier than the last. Combo pickups multiply score.
